# Конвертер единиц измерения (Unit Converter)

## Описание проекта

Конвертер единиц измерения - это приложение на Python с графическим интерфейсом. Оно предназначено для быстрого преобразования распространённых единиц измерения. Программа имеет простой интерфейс, в котором пользователь может выбрать нужную категорию и выполнить перевод.

## Цель проекта

Проект разработан для упрощения перевода единиц измерения, практики программирования на Python, создания графического интерфейса и работы с Git и GitHub.

## Функции программы

1. Перевод километров в метры и обратно.
2. Перевод килограммов в граммы и обратно.
3. Перевод градусов Цельсия в Фаренгейты и обратно.
4. Выбор категории и единиц измерения.
5. Проверка введённого значения и обработка ошибок.
6. Поддержка ввода дробных чисел через точку или запятую.
7. Отображение результата с двумя знаками после запятой.

## Используемые технологии

- Python
- Tkinter
- Git
- GitHub
- Markdown

## Требования

Для работы программы необходимы:

- Python версии 3.x
- Операционная система Windows или другая ОС с поддержкой Tkinter.
- Терминал для запуска программы.

Скачать Python можно с [официального сайта](https://www.python.org/).

## Установка

1. Установить Python.
2. Скачать или клонировать репозиторий с GitHub.
3. Открыть папку проекта в терминале.
4. Проверить наличие файлов `main.py` и `test_converter.py`.
5. Подготовить программу к запуску.

## Запуск программы

Для запуска программы используйте команду:

```bash
python main.py
```

В Windows также можно использовать команду:

```bash
py main.py
```

## Пример использования

1. Открыть программу.
2. Выбрать категорию «Расстояние».
3. Ввести значение 5.
4. Выбрать перевод из километров в метры.
5. Нажать кнопку конвертации.

**Результат:** 5000.00 метров.

## Тестирование

Для проверки работы функций конвертации используется модуль `unittest`.

Запуск тестов:

```bash
py -m unittest test_converter.py -v
```

Программа проверяется на перевод расстояния, массы и температуры, включая перевод температуры в одинаковые единицы.

Всего создано **5 автоматических тестов**.
