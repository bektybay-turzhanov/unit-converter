# Unit Converter - Конвертер единиц измерения

## О проекте

Unit Converter - это учебное приложение на Python с графическим интерфейсом Tkinter. Программа предназначена для преобразования различных единиц измерения. Пользователь может выбрать категорию, указать исходную и целевую единицу измерения, а также получить результат перевода.

## Цель проекта

Цель проекта - создать простую программу для быстрого перевода единиц измерения, а также закрепить навыки программирования на Python и работы с графическим интерфейсом.

## Возможности

- Перевод единиц расстояния (километры и метры).
- Перевод единиц массы (килограммы и граммы).
- Перевод температуры (Цельсий и Фаренгейт).
- Ввод чисел с точкой или запятой.
- Проверка правильности введённых данных.
- Вывод результата с точностью до двух знаков после запятой.
- Обработка ошибок при неправильном вводе.

## Используемые технологии

- **Python** - основной язык программирования.
- **Tkinter** - создание графического интерфейса.
- **Unittest** - тестирование функций программы.
- **Git и GitHub** - управление версиями и хранение проекта.
- **Visual Studio Code** - редактирование кода.

## Требования

Для работы с проектом необходимы:

- Python 3.10 или новее.
- Visual Studio Code или другой редактор кода.
- Операционная система Windows, Linux или macOS.
- Git (для работы с репозиторием GitHub).

## Установка

1. Установите Python с официального сайта: https://www.python.org/
2. Скачайте проект с GitHub.
3. Распакуйте архив проекта.
4. Откройте папку проекта в Visual Studio Code.
5. Убедитесь, что Python установлен и доступен в терминале.

## Запуск

Для запуска программы откройте терминал в папке проекта и выполните команду:

```bash
python main.py
```

В Windows также можно использовать команду:

```bash
py main.py
```

После запуска откроется окно приложения.

## Пример использования

1. Запустите программу.
2. Выберите категорию, например **Расстояние**.
3. Укажите исходную единицу измерения, например километры.
4. Выберите целевую единицу измерения, например метры.
5. Введите значение и нажмите кнопку конвертации.
6. Программа покажет результат.

**Пример:** 5 километров = 5000 метров.

## Тестирование

Для проверки работы программы используется модуль Unittest.

Запуск тестов выполняется командой:

```bash
python -m unittest test_converter.py -v
```

Тесты проверяют преобразование расстояния, массы и температуры, а также обработку одинаковых температурных единиц.
